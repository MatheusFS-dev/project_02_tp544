# Inverse design proposals

Source-derived summary of docs/design/idea.md and docs/reference/Single_Model_Inverse_Design_Full_320nm.pdf pp. 1–5. These are proposals, not implemented behavior.

idea.md: [A,B,X] → residual MLP → [geometry, substrate, outer, inner]. Shared three-block width-256 trunk, four-way geometry head, two-way substrate head, two regression outputs. Sum geometry/substrate classification and dimension regression losses. Offline select consistent best catalogue labels because inverse solutions are not unique. Proposed target is minimum absorption X throughout [A,B], explicitly presented as a decision still to be made. Mentions 400 simulated configurations, but supplied CSV results are empty.

Technical PDF: exactly one trainable multi-head network, one training run, no model comparison, HPO or inference optimization. Input 450≤a<b≤1600 nm and 0≤X≤1, fixed normal-incidence TM. Normalize wavelengths by (λ−450)/1150. Trunk Linear(3,256), SiLU, three width-256 residual blocks with LayerNorm and SiLU. Joint eight-way geometry/environment head, two-coordinate hard-sigmoid dimension head. FP32. Dimensions span full 0–320 nm, inner≤outer, solids have inner=0. Exact endpoints allowed, no rounding or minimum wall/gap. Zero-volume limits require appropriate CAD representation. Consult p. 3 retained source/figure for exact decoder equations, which are graphical in PDF extraction.

Offline deterministic catalogue label construction uses validated spectra on a proposed 1 nm reporting grid with interpolated endpoints. Objective zero when all resolved in-band samples meet X, fixed tie-breaker such as normalized gold area. Consult p. 2 for exact graphical objective. Generate 10,000 seed-42 synthetic queries including unmet requests and narrow/wide bands, balanced across wavelengths/thresholds. Split geometric designs before constructing labels, keeping paired substrates together. Canonicalize physically equivalent limits. Synthetic queries are not independent electromagnetic simulations.

Fixed training: AdamW lr=1e-3, weight decay=1e-4, 200 epochs, batch size 128, seed 42. Eight-class cross-entropy plus normalized-coordinate Huber with respective weights 1 and 2. 64 train / 16 held-out geometries. Catalogue assumes 160 standard spectra plus 8 higher-fidelity checks.

Inference: one forward pass, class argmax and valid dimensional decode, return geometry/environment and verification status. One independent HFSS verification solve where possible. Report categorical accuracy, dimensional error in nm, minimum and average in-band simulated absorption, nonnegative threshold violation, feasible-request success. Confidence does not establish physical feasibility. Very narrow bands depend on solved spectral density, not export spacing. Tiny walls/gaps and exact boundary predictions can be expensive or unresolved. Report unverified status rather than clipping domain. See p. 5 for exact graphical violation metric. Training and additional verification are outside the stated two-week generation budget unless separately covered.
